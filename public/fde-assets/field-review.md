# FDE 交付评审与复盘

本站教学模板，不是招聘认证或统一行业标准。

## 1. 业务发现
- 使用者 / 业务负责人 / 技术负责人：
- 当前流程、问题、范围外事项：
- 现状基线、测量日期、样本与证据：
- 数据许可、权限、系统依赖：
- 正常任务发起、执行、审核放行、验收及日常维护的执行人与最终确认人：
- 各事项替补人、处理时限与完成证据：
- 交付、运行、人工审核、运维及变更费用的估算依据、付费方和批准人：
- 包含范围、另行采购、结算节点、预算上限和追加批准方式：

## 2. 工程实现
- 代码仓库或工作流导出、版本、复现步骤：
- API / 连接器、鉴权、数据契约：
- 超时、重试、幂等、人工接管：
- 技术取舍及被排除方案：

## 3. 评估与上线
- 样例集与标注者；典型、边界、拒答及越权样例：
- 任务成功率分母、失败定义、延迟与成本测量方法：
- 相对基线变化、未解决问题和限制：
- 灰度范围、监控、回滚触发条件与责任人：
- 演练证据；模拟环境不得记为真实生产上线：

## 4. 用户采用
- 试用人群、观察周期、使用障碍：
- 真实完成任务与人工介入记录：
- 反馈与下一轮优先级；无真实用户时仅提交验证计划：

## 5. 交接与产品反馈
- 运行手册、维护人、验收人与日期：
- 客户特例与可复用能力：
- 可复用连接器 / 评测集 / 模板：
- 向产品团队反馈的问题、复现步骤和影响范围：
